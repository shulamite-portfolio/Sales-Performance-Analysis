# Sales-Performance-Analysis

##  Tool used
*Microsoft Excel

## Project Overview
This Project analyzes Monthly Sales Performance of an Electronic Brand.
It explores the profit margin by product, Monthly trend, Sales by city and Sales Rep Performances.

## What I Learned
*How to do Data cleaning in Excel using formulas
*How to summarise KPIs using Pivot Tables
*How to Visualize insights in Excel
*How to create an interactive Dashboard using Excel
